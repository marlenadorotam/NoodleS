# ParametricObject

A generating node describes geometry as immutable values and recipes organized in a DataTree. In Serpentine3D, NoodleSBridge builds the native result through OpenCascade and publishes it as a single scene owner. The same mechanism handles a single curve, a grid with points and edges, or hundreds of different solids generated by one node.

## From graph to scene

The graph passes geometry values downstream without creating individual `SceneObject` records. The adapter resolves parts into OCC geometry and prepares native display data on a worker. Qt applies the complete result in a scene transaction with rollback. The current valid result stays visible while a new one is prepared. Newer requests supersede outdated work and the document identity is checked before commit.

The ParametricObject model is in [parametric.py](../noodles/backend/parametric.py). [GeometryService](../noodles/point_service.py) exchanges requests with the bridge, and the [scene adapter](../noodles/backend/scene_points.py) handles native publication. A scene object may contain a compound. The DataTree still exposes separate values, paths, and stable part keys for downstream nodes.

## Identity, attributes, and editing

A publication binds a graph project, node, and output to its owner. The scene stores persistent binding markers and a manifest in user text. The graph stores node identities and configuration. This lets the bridge resolve owners when Serpentine3D issues new runtime IDs on reopening. Part keys are stable across compatible edits and independent of native face array indices.

Rebuilding an existing owner retains its name, layer, color, visibility, and other scene attributes. Edit those attributes in Serpentine3D. Geometry follows the generating graph. To drive a native source in place, use a supported node in [Reference mode](reference-editing.md). Referencing an object keeps it under its existing ownership.

## Ungroup Parametric Object

Select a published result in Serpentine3D and run `ungroupparametric`, or right-click its generating node in NoodleS and choose **Ungroup Parametric Object**. The command replaces the owner with independent native objects, expanding compounds while keeping complete solids and curve wires intact. Parts inherit the relevant layer, color, and user text. The detached pieces no longer carry graph binding markers.

The node remains enabled and still evaluates. A record saved in the scene prevents it from republishing that result. Undo in Serpentine3D restores the original object and binding in one step. [Deletion and undo](geometry-deletion.md)
